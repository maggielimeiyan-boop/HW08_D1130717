## 3. 問題問答

### 問題一：為什麼 "4" 要先轉成數字，才能用於本題的分攤計算？
答：因為 `"4"` 是字串型別，Python 無法直接對字串執行數學除法運算。必須透過 `int()` 轉換為整數後，才能進行正確的數值除法並計算出每人分攤費用。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼題目和規定的結果不一樣？
答：會變成 1,210 元。因為餐廳的服務費通常是以原價為計算基準（反映真實服務成本），而折扣券是商家給予的優惠折抵，順序不同會導致計費基底改變，因而產生 10 元的落差。
